# ComfyUI-StageBridge

Install this folder as `ComfyUI/custom_nodes/ComfyUI-StageBridge` and restart ComfyUI. Remove an older `ComfyUI-RemoteTE` installation first to prevent duplicate class registrations.

Set each node's `server_url`, or use `REMOTE_TE_SERVER_URL` / `REMOTE_TE_H3_SERVER_URL` for defaults. `REMOTE_TE_API_TOKEN` supplies optional authentication. See the repository setup guide for checkpoint fingerprints, model requirements, supported modes and timeouts.
